# 底部入口与默认后台运行

底部删除「后台运行」与「减少动态效果」两个按钮，两端仅保留设置、语言和主题等主入口。没有用隐藏占位保留空槽；原生安装包 smoke 同样检查这两个旧控件不存在。

## 关闭与退出

`AppSettings.CloseAction` 默认值及无效值归一化改为 `MinimizeToTray`。新配置和缺少该字段的旧配置使用后台行为；已有明确保存的 Ask/Exit/MinimizeToTray 仍保留。应用正常启动仍显示主窗口，不因默认关闭行为改变而静默启动。

点击关闭可走既有隐藏/后台生命周期；macOS 从 Dock/菜单栏恢复，Windows 从托盘恢复，无托盘时保留任务栏最小化入口。明确退出、⌘Q 和测试用 `--exit-on-close` 仍退出。没有改变行情监控节奏或后台资源回收机制。

## 减少动态效果

在设置 → 外观增加现有样式的复选控件，沿用 `AppCard`、`AppFormHeader`、`AppHelp` 与表单尺寸。保存到原来的 `web-workspace.json`，不迁移/丢弃已有动效选择或网页标签；系统减少动态设置始终优先。

桌面组合注册同一个 `WebWorkspace` 给主窗口与设置，成功提交后通知窗口和 `DesignMotion`，即时更新内置页面/控件。窗口关闭时解除订阅；新窗口重新校验文件。冲突时回滚开关并显示错误，不覆盖其他进程新写入的书签；读到损坏文件后禁止用旧内存状态覆盖它。

此项是既有桌面呈现偏好，继续列入能力清单的 UI-only 范围；不引入 MCP 浏览器或窗口控制。默认 closeAction 仍可通过既有 get_settings/update_preferences 管理。
