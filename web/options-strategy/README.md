# Options and strategy core

One signed domain with twelve unchanged CLI/MCP operations. Reuses shared providers, pricing, Analytics, stores and managed caches. Native full-chain source receipts, draft editing and private workbench rendering stay host-owned to avoid paging or process startup per slider update. Public writes require explicit permission and a single exact-argument, request-owned delegation; the engine cannot write another strategy or repeat a mutation. Uninstall retains strategies and IV/OI history. No broker or order execution capability.

Generic calculate_option/calculate_indicators remain host-owned primitives, including when an app registry needs recovery.
